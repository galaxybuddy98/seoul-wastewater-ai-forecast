# Multi-agent 효율화 설정 계획

> **에이전트 작업자용:** 이 계획은 메인 에이전트가 직접 실행한다. 불필요한 Subagent를 생성하지 않는다.

**목표:** 기존 코드와 데이터를 변경하지 않고, 검증된 Codex 기능만으로 토큰 절감형 작업 분담 정책을 적용한다.

**구조:** 프로젝트 루트 `AGENTS.md`에 메인 직접 처리 원칙, 조건부 위임 기준, 모델·추론 강도, 동시 실행 상한과 수질 프로젝트 안전 규칙을 기록한다. 현재 세션에서 이름 있는 `agent_type`이 지원되지 않으므로 `.codex/agents/*.toml`은 생성하지 않는다.

**기술 환경:** Codex CLI 0.165.0, Multi-agent, Markdown

**설계 근거:** 사용자가 승인한 모델 운영 정책과 현재 세션의 실제 `spawn_agent` 스키마

## 전역 제약

- 메인은 `gpt-5.6-sol / low`를 유지한다.
- 경량 위임은 `gpt-5.6-terra / low`, 고난도 검토는 `gpt-5.6-sol / medium`만 사용한다.
- 활성 Subagent는 최대 2개이며, 짧거나 의존적인 작업은 메인이 처리한다.
- 기존 코드, CSV, API 수집·전처리 구현을 수정하지 않는다.
- 검증되지 않은 커스텀 에이전트 TOML을 만들지 않는다.

## 검토 초점

- `light`·`middle` 표현이 실제 설정값 `low`·`medium`으로 정확히 매핑되는가
- 단순 작업 위임 금지와 독립적 읽기 전용 작업의 경계가 명확한가
- 원본 데이터 보호와 시계열 누수 방지 원칙이 유지되는가
- 동시 Subagent 2개 제한이 명시되는가
- 지원되지 않는 `.codex/agents` 설정이 생성되지 않는가
