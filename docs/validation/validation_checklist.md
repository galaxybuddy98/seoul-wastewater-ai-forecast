# 예측 검증 체크리스트

`forecast-validation` 스킬을 수질 예측 문맥에 맞춰 적용한 기록 양식이다. 답이 없는 항목은 **미확인**으로 남기며 성능 주장에 사용하지 않는다.

| 항목 | 현재 기록 |
|---|---|
| 예측 계약 | 날짜×원본 처리장·유입 관측 계통, 기준일 t 종료 후 t+1 BOD·T-N·T-P |
| 시간 분할 | Train 2016~2022, Validation 2023~2024, Test 2025~2026-09-30 |
| rolling-origin | 미실시; 미사용 기간 또는 학습·검증 범위 추가 검증 필요 |
| 누수 검사 | 입력 종료일 `target_date-1`, 계통별 윈도 분리, Train-only 전처리, Test 선택 금지 확인 |
| 결측 처리 | 수질 필수값과 날짜 연속성 유지, 트리 모델은 선택 기상 피처의 NaN 허용 |
| 이상치 처리 | 자동 삭제·보간 없이 원문과 후보 플래그 보존 |
| 외부 변수 | ASOS 기온·서울시 강우 사용; 실제 공개 시점과 센터 강우 공간 대표성 미확인 |
| 기준모델 | Persistence |
| 지표 | 동일 평가 키의 MAE·RMSE·R², Persistence 대비 MAE 개선율 |
| 슬라이스 | 7개 평가 계통·계절·요일·고농도 구간의 표본수와 오차 |
| 과적합 | Validation 선택, 반복 확인된 Test 한계 명시, LSTM 단일 seed 한계 유지 |
| 재현성 | 원본 SHA-256, 시간 분할, 피처 목록, seed, 모델·예측·지표 저장 |

## 현재 판정

LightGBM·XGBoost·LSTM 학습과 공통 평가 키 비교를 완료했고 목표별 XGBoost를 Validation MAE로 선택했다. Test는 반복 확인된 참고 구간이며, 실측 입력 공개 시점과 강우 관측소 대표성이 확정되지 않아 현재 결과는 오프라인 후향적 평가로 분류한다.

## 프로젝트 맞춤 차이

원 스킬의 수요·대여소·행사 관련 문구를 유입수질·센터·기상/운영 변수로 해석한다. GIS와 행사 변수는 현재 범위에 없으므로 적용하지 않는다. 날씨의 예측시점 가용성 원칙은 그대로 적용한다.
