CSV는 API 검증용이며 최종 수집은 ViewQowRep, ViewTreQty, ASOS API를 유지한다.

API 대조 시 총행수·기간·복합키 값·페이지 누락, 구분없음/시설현대화 설명, 처리량 단위와 1·2차 정의, 채수·계측 경계, 공개 시각을 확인한다.

모델 전 단계 완료 조건은 중랑·서남 통합 근거, 난지·탄천 대표성, 탄천 누락 원인, ASOS 가용성, 예측시점 변수 이용 가능성 확정이다. 시간 분할은 학습 2016~2022, 검증 2023~2024, 잠긴 테스트 2025~2026-09-30을 유지한다.


## 후속 확인이 필요한 공식 메타데이터

- 물재생시설과에 ViewTreQty 1차·2차 처리량의 단위, 계측지점, 상호배타성, 합산식 문의
- 중계펌프장·정화조오니처리장의 센터 총량 포함 여부 확인
- 서남 시설현대화와 제1·제2처리장의 일별 계통 이관표 확보
- ViewQowRep 유입수 채수지점과 처리장 구분없음의 대표 범위 확인
- 처리장별 실제 유입유량과 수질 채수 경계 대응표 확보
- 서울시·기상청 API 인증키 준비 후 CSV 복합키·값 대조 및 ASOS 실자료 수집

ASOS 자료가 준비되면 일평균기온·일강수량으로 강수-처리량·수질·이상치·예측오차 관계를 분석한다. 3일·7일 누적강수량을 별도 기본 특징으로 추가하지 않고 7·14·30일 과거 입력창 비교를 유지한다. 실제 자료 전에는 관계를 추정하지 않는다.
# 서울시 강우량 자료 요구사항

- 원본은 `data/external/seoul_rainfall/`에서 읽기 전용으로 취급한다.
- 10분 구간 144개가 모두 수치이고 중복 충돌·음수가 없을 때만 일강우량을 확정한다.
- 기록이 없는 구간이나 날짜는 공식 무강수 규칙이 별도로 확인되지 않는 한 0 mm로 바꾸지 않는다.
- 누적강우는 구성일에 미확정값이 있으면 `NaN`을 유지한다.
- 센터별 관측소는 위치·운영기간·완전성·처리구역 대표성을 검토하며, 처리구역 대표성이 확인되기 전에는 `provisional`로 관리한다.
- 2026년 1~9월 월별 CSV 9개는 증분 처리 완료했다. 관측소 위치·운영이력 및 처리구역 GIS는 여전히 추가 확보가 필요하다.
