# API 수집 명세

## 서울 열린데이터광장

- 수질 서비스: `ViewQowRep`
- 처리량 서비스: `ViewTreQty`
- 요청 형식: `http://openapi.seoul.go.kr:8088/{KEY}/json/{SERVICE}/{START}/{END}/`
- 페이지: 시작·종료 인덱스, 요청당 최대 1,000행
- 오류: HTTP 상태뿐 아니라 응답 본문의 `RESULT.CODE`도 검사
- 수집: 재시도 가능한 세션, 연결/읽기 타임아웃, 페이지 원문 캐시, 다음 시작 인덱스 체크포인트

인증키는 환경변수에서 읽고 로그·캐시·예외 메시지에서 마스킹한다. 전체 건수보다 마지막 인덱스가 커지면 종료하며, 재실행 시 캐시와 체크포인트로 이어받는다.

## 기상청 ASOS

- 서비스: `AsosDalyInfoService/getWthrDataList`
- 필수 조건: `dataCd=ASOS`, `dateCd=DAY`, 시작·종료일, 관측소 ID
- 형식: JSON
- 관측소 선택은 센터 대표성·가용 기간·결측률을 비교한 뒤 확정

## 검증

페이지별 행 수, 인덱스 연속성, 복합키 중복, 응답 총건수, 최소·최대일을 기록한다. CSV 대조는 별도 보고서에 남기며 API 원문을 수정하지 않는다.
