# 위험 등록부

| 번호 | 위험 | 완화 및 판정 관문 |
|---|---|---|
| R1 | API 실제 가용 범위가 2016~2026 기준과 다름 | 전체 건수·최소/최대일 확인 후 분할 갱신 |
| R2 | 페이지 제한·일시 오류로 누락 | 1,000행 페이지, 재시도, 원문 캐시, 체크포인트, 페이지 연속성 검사 |
| R3 | 처리장·계통·구분없음의 잘못된 통합 | 공식 구조와 보존식 확인 전 센터 집계 금지 |
| R4 | TP/T-P, COD/TOC, 유입/방류 의미 혼동 | 원본 열과 의미 라벨을 함께 보존 |
| R5 | 0을 결측으로 일괄 처리 | 변수·센터·기간별 빈도와 주변값을 검토해 규칙화 |
| R6 | 이상치 자동 삭제로 사건 신호 손실 | 후보 플래그만 만들고 원문 유지, 근거 있는 민감도 분석 |
| R7 | 보간·스케일링·rolling에서 미래 누수 | fold 내부 fit과 shift 선행 테스트 |
| R8 | 미래 실측 날씨 사용 | 예보 스냅샷 없으면 날씨 제외 또는 oracle로 분리 |
| R9 | 테스트 구간으로 모델 선택 | 2025~2026-09-30 잠금, 선택 완료 후 1회 평가 |
| R10 | CSV와 API 불일치 | 행 수·키·표본값·기간을 대조하고 API를 최종 원천으로 사용 |
| R11 | API 키·CSV 부재 | 합성 테스트까지만 완료로 표시하고 사용자 입력 항목 명시 |
| R12 | 라이선스상 원자료 재배포 제한 | 이용조건 재확인, 코드·메타데이터 중심 공개 |
| R13 | 센터별 표본 불균형 | 전체 micro와 센터 macro·개별 표본수를 함께 보고 |
| R14 | 공개 지연 미확인 | 운영 성능을 주장하지 않고 후향적 평가로 제한 |

## 중단 기준

시계열 구조나 측정 정의를 복원할 수 없으면 임의 집계하지 않는다. 핵심 타깃의 연속 일별 자료가 부족하면 모델 단계 전에 범위와 연구 질문을 재검토한다.
