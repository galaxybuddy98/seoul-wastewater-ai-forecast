# 센터별 유입수질 통합 규칙

최종 단위는 측정일자×물재생센터이며 목표는 다음 날 유입 BOD·T-N·T-P다. 방류는 제외한다.

## 확정 공통 규칙

- 계통이 유입수인 행만 목표 후보로 사용한다.
- 복합키 중복은 0건이다.
- 1차와 2차 처리량 합산, 처리장 농도 산술평균을 금지한다.
- 처리량이 실제 유입유량임을 확인하기 전에는 가중치로 쓰지 않는다.
- 날짜 누락, 값 결측, 0, 이상치 후보를 별도 보존한다.

| 센터 | 판정 | 조건부 규칙 | 추가 확인 |
|---|---|---|---|
| 난지 | 조건부 가능 | 구분없음 1행 직접 사용, 제1처리장 추가 2행 제외 후보 | 구분없음 대표성, 추가 행 성격 |
| 탄천 | 조건부 가능 | 구분없음 1행 직접 사용, 없는 날짜 결측 | 192일 누락과 대표성 |
| 서남 | 일부 기간 조건부 | 2019-06 이후 구분없음 직접 사용 후보 | 이전 제1·2 통합, 현대화 중첩, 2021-01-31 전환 |
| 중랑 | 보류 | 처리장별로 분리 보존 | 실제 유입유량, 채수 경계, 대표값 |

서남은 제1·2 유입(2016~2021-01-31), 구분없음(2019-06 이후), 시설현대화(2020-07~2021-01-31)가 중첩한다. 구분없음이 기존·현대화 시설의 공식 대표인지 확인 전에는 전 기간 단일 규칙을 적용하지 않는다.

유량가중평균은 처리량이 해당 처리장의 실제 유입유량이고 농도 채수 경계가 일치하며, 사용할 1차/2차 변수가 명확하고 내부순환·중계펌프·오니가 중복되지 않는다는 근거가 모두 확보될 때만 승인한다.


## 2026-11-11 후속 판정

### 처리량

공식 ViewTreQty 메타데이터는 1차하수처리량(SEWAGE_PRCS_QY_1)과 2차하수처리량(SEWAGE_PRCS_QY_2)을 별도 필드로 제공하지만, 계측지점·단위·상호배타성·합산식을 설명하지 않는다. 따라서 1차가 1차 처리 후 방류량이라는 해석과 두 값의 무조건 합산은 확인되지 않았다.

코드에서는 두 성분이 모두 관측된 행에만 total_treatment_volume_hypothesis = primary + secondary를 만들고, 어느 한 성분이 결측이면 합계도 결측으로 둔다. 이 값은 계산 가설이며 공식 총하수처리량 또는 실제 유입유량이 아니다. 원 성분은 항상 보존한다.

난지의 중계펌프장(상암)과 정화조오니처리장은 API에서 별도 처리장 행으로 존재하지만 센터 총량 포함 관계가 공개되지 않았다. 서남 시설현대화는 36만 톤/일 규모로 2022년 2월 1단계가 완료됐으나, 기존 제1·제2처리장과의 일별 이관·중복 관계는 확인되지 않았다. 이 행들은 자동 센터 합산하지 않는다.

### 센터별 유입수질 선택

| 센터 | 현재 방법 | 판정 |
|---|---|---|
| 난지 | 처리장 구분없음 직접 사용 후보 | 전 기간 일별 행은 있으나 제1처리장 2건과 채수 대표성 확인 전 조건부 |
| 탄천 | 처리장 구분없음 직접 사용 후보 | 192일 누락 때문에 사용 기간·입력창별 표본 플래그 필요 |
| 서남 | 2019-06 이후 처리장 구분없음 직접 사용 후보 | 제1·제2·시설현대화 중첩 기간은 혼합하지 않고 운영 이관 확인 필요 |
| 중랑 | 처리장별 예측 대안 | 실제 유입유량과 채수 경계가 없으므로 센터 농도 통합 보류 |

처리량 합산 가설은 농도 통합 규칙과 무관하다. 유량가중평균은 해당 수질 측정 지점과 동일 경계의 실제 유입유량임이 확인될 때만 검토한다.
