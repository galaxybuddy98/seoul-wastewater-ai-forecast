# 서울 ASOS 108 시간강수 검증 보고서

## 결론

기상청 ASOS 시간자료 API 인증과 전체 기간 수집에 성공했다. 그러나 시간자료는 기존 일자료 `sumRn` 공란 2,345일을 추가로 확정하지 못했다. 공식 근거 없이 공란을 0mm로 바꾸지 않았으므로 시간자료 검증 후에도 일강수 결측률은 59.73%로 동일하다.

- 목표기간: 2016-01-01~2026-09-30, 3,926일
- 서울 108 일계 검증에 사용한 시간행: 94,224행
- 시간 시각 중복·일별 시각 행 누락: 0건
- 일자료 수치 존재: 1,581일(0.0mm 434일, 양수 1,147일)
- 시간자료로 추가 복원: 0일
- 시간자료로 무강수 0mm 확정: 0일
- 미확인 NaN 유지: 2,345일

원본 일자료, 시간자료, 기존 모델과 C·D 실험 결과는 수정하거나 덮어쓰지 않았다. 모델 재학습도 수행하지 않았다.

## 공식 명세와 실제 응답

[공공데이터포털 데이터 ID 15057210](https://www.data.go.kr/data/15057210/openapi.do)은 `rn`을 시간자료 강수량, `rnQcflag`를 강수량 품질검사 플래그로 정의한다. 실제 JSON 응답 키는 `rnQcflg`였으며 두 필드를 모두 수집했다.

[기상자료개방포털 ASOS 자료 설명](https://data.kma.go.kr/data/grnd/selectAsosList.do?pgmNo=36)은 다음을 명시한다.

- 시간자료는 한 번에 최대 1년 조회
- 겨울철 11월~다음 해 3월 강수량은 3시간 간격 제공
- QC FLAG의 일반 값은 0 정상, 1 오류, 9 결측

현재 ASOS 페이지의 QC 적용 요소 목록에는 강수량이 빠져 있지만, 데이터 ID 15057210의 출력 명세와 실제 응답에는 강수 QC 필드가 존재한다. 따라서 필드는 보존하되, QC 공란을 정상 또는 무강수로 간주하지 않았다.

실제 목표기간 `rnQcflg` 분포:

| 계절 | 0 | 1 | 9 | 공란 |
|---|---:|---:|---:|---:|
| 겨울(11~3월) | 402 | 0 | 7,305 | 30,765 |
| 비겨울(4~10월) | 1,790 | 0 | 9,511 | 44,451 |

## 시간 경계 검증

시간 `rn`을 응답의 달력일에 그대로 합산하면 공식 일자료와의 일치율은 67.56%였다. 00시 관측을 전날 일계에 귀속해 `00:01~24:00` 구간으로 합산하면 다음 결과를 얻었다.

- 비교 가능 일수: 1,581일
- ±0.05mm 이내 일치: 1,579일
- 일치율: 99.873%

따라서 `rn`은 해당 시각 직전 구간의 강수량으로 해석하고 00시 값을 전날에 귀속했다. 마지막 목표일인 2026-09-30의 일계를 닫기 위해 2026-10-01 00시 자료를 함께 확보했다.

불일치 2일은 공식 일자료를 우선했다.

| 날짜 | 공식 `sumRn` | 시간합계 | 차이 |
|---|---:|---:|---:|
| 2022-09-05 | 120.0 | 119.8 | -0.2 |
| 2026-05-02 | 1.4 | 0.8 | -0.6 |

두 날짜의 시간 강수 QC는 공란이었다. 분자료 집계, 자료 수정 이력 또는 미량값 차이일 가능성이 있으나 원인은 확인되지 않았다.

## 표본 날짜 검증

| 날짜 | 선정 사유 | 일자료 | 시간자료 판정 |
|---|---|---:|---|
| 2016-01-01 | 일자료 공란 | NaN | 수치 강수 없음, C 유지 |
| 2016-01-13 | 겨울철 강수 | 0.4 | 3시간 간격 수치 합계 0.4, 일치 |
| 2016-01-14 | 명시적 0.0mm | 0.0 | 시간 수치 합계 0.0, 공식 일자료 A 유지 |
| 2022-06-30 | 여름 집중강수 | 176.2 | 시간합계 176.2, 일치 |
| 2025-05-14 | 지속시간 양수·`sumRn` 공란 | NaN | 다음날 00시 0.0 한 건 외 공란, 수치 복원 불가 |

### 2025-05-14

일자료에는 강수 지속시간 0.5시간과 `n99Rn=1.0mm`가 있지만 `sumRn`은 공란이다. 시간 일계 구간에는 수치 0.0 한 건만 있고 나머지는 공란이며, 09시 경계 자료에서도 1.0mm를 확인하지 못했다. 미량강수, 다른 집계 경계 또는 자료 생성 차이가 가능하지만 원인은 확정할 수 없다. 상태 C로 두고 NaN을 유지했다.

## 일강수량 판정 규칙

| 상태 | 적용 규칙 | 결과 일수 |
|---|---|---:|
| A | 공식 `sumRn` 수치가 있거나, 오류·중복 없이 시간 양수가 직접 관측된 경우 | 1,581 |
| B | 공식 기록 간격을 고려한 반환 시간값이 모두 QC 정상 0.0으로 확인된 경우 | 0 |
| C | 공란·미량강수 가능성 또는 수치 미확인 | 2,345 |
| D | QC 오류, 시각 중복 또는 시간자료 부재 | 0 |

시간 API가 매일 24개 시각 행을 반환한 사실만으로 관측 완전성을 판단하지 않았다. 겨울에는 강수가 3시간 간격으로 제공되고, 무강수·미보고 시각의 `rn`과 QC가 공란일 수 있기 때문이다.

## 파생변수와 기존 데이터셋 연결

검증 강수량을 이용해 1~3일 전 강수량과 최근 3일·7일 합계를 별도 산출물에 생성했다. 누적기간에 NaN이 하나라도 있으면 합계도 NaN이다.

| 변수 | 수치 가용 일수 |
|---|---:|
| 1일 전 강수 | 1,580 |
| 2일 전 강수 | 1,580 |
| 3일 전 강수 | 1,580 |
| 최근 3일 합계 | 496 |
| 최근 7일 합계 | 112 |

처리장·유입 관측 계통별 데이터셋에는 날짜로 many-to-one 연결했다. 기존 Train/Validation/Test, 수질·기온, 계통 구분 및 LightGBM NaN 허용 규칙을 유지했다. t+1 목표행에는 입력 종료일까지의 강수만 포함된다.

강수 검증 결과가 기존 보수적 전처리와 동일했으므로 C·D의 7·14·30일 Train/Validation/Test 표본 수는 변경 전후 모두 동일했다. 상세 수치는 `rainfall_hourly_dataset_comparison.csv`에 있다.

- `reports/asos_hourly_validation_summary.json`: 기계 판독 요약
- `reports/rainfall_hourly_dataset_comparison.csv`: 표본 수 전후 비교

## 재현

```powershell
python -m scripts.data_collection.collect_asos_hourly
python -m scripts.preprocessing.build_hourly_validated_rainfall
python -m pytest
```

현재 검증 강수량은 기존 값과 동일하므로 즉시 모델을 재학습할 실익은 없다. KMA가 공란·미량강수 기록 규칙을 추가로 확인해 주거나 분자료로 B/C를 구분할 수 있을 때 재학습 여부를 다시 판단하는 것이 적절하다.
