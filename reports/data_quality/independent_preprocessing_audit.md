# 데이터 전처리 독립 감사 보고서

## 감사 범위와 독립성

- 감사일: 2026-11-14, 고정 시드: 20261114
- 기존 집계·결합·윈도 함수를 호출하지 않고 원본 CSV와 저장 산출물을 별도 코드로 대조했다.
- 모델 재학습, API 호출, 원본 수정, 전체 강우 원본 재처리, GitHub Push는 수행하지 않았다.
- 이번 SHA-256은 현재 파일의 향후 변경 검증 기준선이다. 과거 해시가 없는 파일은 과거에 수정되지 않았다는 증거가 아니다.

## 원본과 행수 계보

- 원본 CSV 947개, 1,238,028,181바이트의 SHA-256을 스트리밍 계산했다.
- 기존 과거 해시는 9개만 있었고 현재 값과 불일치한 파일은 0개다.
- 강우 원본 인벤토리 행수는 38,322,021건, 관측소 일자료는 270,894건, 센터 일자료는 15,704건이다.
- 수질 원본은 74,917행 중 유입수 28,828행이며 계통 일자료는 28,828행이다.

## 독립 강우 재계산

- 층화 표본 650개 관측소-일을 원본 파일에서 직접 재계산했다. 일치 650건, 불일치 0건, 일치율 100.000%다.
- 공항동P 167, 성동구청 167, 마포구청 160, 세곡동 156건이며 Train 305, Validation 177, Test 168건이다.
- 2016~2026년 모든 연도를 포함하며 2026년은 73건이다. 무강우 269, 일반 강우 143, 집중강우 94, 불완전 관측 144건과 원본 10분 행 81,395건을 확인했다.
- 불완전·충돌 관측을 0mm로 확정한 표본은 0건이다.
- 서울 데이터 허브는 `10분우량`을 자료수집시각 직전 10분 구간의 누적 강우량으로 설명한다. 예: 13:09 값은 13:00:00~13:09:59 구간이다.
- 과거 파일은 계측 원시자료이며 보정되지 않았다고 안내되어, 통계 이상치를 감사 코드에서 임의 수정하지 않았다.

## 수질·기상·모델 입력

- 수질 원본-가공 값 일치: 28,828/28,828행, 불일치 0행, 원본 키 중복 0건이다.
- 하나의 series_id가 여러 센터·처리장으로 섞인 경우는 0건이다.
- 결합 점검 불일치는 총 0건이며 항목별 상세는 `audit_join_checks_2026-11-14.csv`에 있다.
- 분할·연도 경계를 명시적으로 포함한 30일 윈도 128개에서 19,584개 값을 독립 복원했고 불일치는 0개다.
- split 불일치 0건, target_date-1 입력종료일 불일치 0건이다.
- LSTM 시퀀스 100개를 오래된 날→최신 날 순으로 복원해 불일치 0건을 확인했다.
