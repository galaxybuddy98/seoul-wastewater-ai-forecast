# 최종 모델 시각화 및 예측 성능 분석

## 분석 범위와 검증

- 기존 저장 예측값만 사용했으며 모델 재학습, 원본 재처리, API 호출은 수행하지 않았다.
- 최종 모델은 Validation MAE로 선정된 BOD `XGBoost C/30 + 계절·요일`, T-N `XGBoost E/30 + 요일`, T-P `XGBoost C/30 + 요일`이다.
- Validation 5,056개, Test 3,831개의 `target_date × series_id × target` 평가 키를 사용했다. 최종 XGBoost와 Persistence 간 키·실제값 일치를 검증했고 중복 키는 0건이었다.
- 7개 계통은 중랑 제1~4처리장, 난지·탄천·서남 처리장 구분없음이다.
- Test는 반복적으로 확인된 참고 평가 구간이며 독립적인 최종 홀드아웃으로 해석하지 않는다.

## 그래프에서 확인된 예측 특성

1. 최종 XGBoost는 완만한 상승·하락과 통상 농도 범위의 중심 수준은 Persistence보다 안정적으로 따라간다. 전체 MAE는 세 항목 모두 약 20% 이상 개선됐다.
2. 급등 시 예측값도 일부 상승하지만 폭이 크게 축소된다. 산점도와 잔차도에서 실제 농도가 높아질수록 `예측-실제` 잔차가 음수로 내려가는 회귀-평균 경향이 세 항목 모두 확인된다.
3. BOD 180 mg/L 이상은 사후 실제값으로 분류한 구간이다. Validation에서 XGBoost 고농도 MAE 55.545, 과소예측률 91.80%, 평균 편향 -53.984 mg/L였다. Test 참고 구간에서는 MAE 67.082, 과소예측률 97.24%로 더 악화됐다. Persistence는 같은 Test 표본에서 MAE 54.889로 고농도 급등에는 더 유리했다.
4. T-P는 낮은 농도 범위의 일반 변동은 따라가지만 큰 실제값에서 예측 상단이 눌린다. Validation 전체 평균 편향도 -0.130 mg/L로 음수이며, 큰 양의 급변을 놓치는 패턴이 보인다.
5. Persistence는 직전 값이 다음 날까지 이어지는 완만한 구간과 고농도 상태가 연속되는 구간에서 강하다. XGBoost는 단기 반전·잡음이 있는 일반 농도 구간에서 Persistence의 하루 지연을 줄이는 쪽이 강하다.
6. 계통 차이가 크다. Validation BOD는 서남 처리장 구분없음이 MAE 12.540으로 가장 낮고, 중랑 제2처리장이 42.089로 가장 높았다. T-N은 탄천 처리장 구분없음이 5.145로 가장 높았고, T-P는 중랑 제2처리장이 1.267로 가장 높았다. 이는 통합 모델의 전역 성능만으로 현장별 성능을 대표할 수 없음을 뜻한다.
7. 실무 제약은 급격한 고농도 상승의 체계적 과소예측, 일부 계통의 낮은 R², 잠정 강우 관측소 매핑, 당일 기상·강우 자료 공개 지연 가능성이다. 고농도 경보 용도로는 점예측만 사용하지 말고 별도 위험 분류·예측구간·Persistence 보조 규칙을 검증할 필요가 있다.

## 입력 자료와 알고리즘 비교 해석

- 동일 표본 B 구성 비교에서 XGBoost는 Validation MAE가 BOD 23.758, T-N 3.353으로 LightGBM·LSTM보다 낮았다. 최종 달력 피처까지 적용한 값은 각각 23.278, 3.198로 추가 개선됐다.
- 서울시 강우량 추가의 Validation MAE 개선은 XGBoost 기준 BOD 1.24%, T-N 4.40%였다. 효과는 존재하지만 핵심 설명력 전체를 강우로 해석할 수준은 아니다.
- SS 추가는 Validation에서 LightGBM BOD -0.36%, T-N -0.24%, T-P -0.22%; LSTM은 BOD -0.77%, T-N +0.46%, T-P -0.35%였다. 알고리즘·항목 전반의 일관된 개선 근거는 없다.
- 피처 실험 그림은 각 원 보고서의 공통 표본 내부 비교를 시각화했다. 서로 다른 실험표의 평균 MAE 막대 높이는 직접적인 모델 우열로 사용하지 않는다.

## 확대 구간 선정

성능이 좋아 보이는 기간을 임의 선택하지 않았다. 각 항목의 Validation 실제값만으로 90일 총 절대 변화량이 최대인 연속 구간을 정했다.

- BOD: 2024-04-08~2024-07-06
- T-N: 2023-04-14~2023-07-12
- T-P: 2024-03-25~2024-06-22

Test 확대 그림에는 같은 월·일의 2025년 구간을 적용했다. 고농도 그림은 실제값 기준 상위 고농도 사건과 전후 7일을 함께 표시하며, 고농도를 예측 시점에 아는 정보로 사용하지 않았다.
