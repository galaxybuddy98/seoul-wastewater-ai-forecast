# XGBoost·LSTM 코드 리뷰 수정사항 최종 검증

검증일: 2026-11-13

## 보존 범위

- XGBoost 모델 12개와 LSTM 모델 12개가 존재함을 확인했다.
- 모델 재학습, 데이터 수집, 원본 전처리, API 호출은 수행하지 않았다.
- 기존 모델·예측·지표·보고서는 덮어쓰지 않았다.
- GitHub Push를 수행하지 않았다.

## 시스템 자원

- 검증 시작 시 가용 물리 메모리: 2,126,644KB(약 2.03GiB)
- 검증 시작 시 가용 가상 메모리: 4,930,808KB(약 4.70GiB)
- 이전 실패 시 약 0.14GB였던 가상 메모리가 회복되어 비교 및 전체 테스트를 한 번씩 실행했다.

## 공통표본 비교

- 동일 윈도 공통 예측: 326,100행
- Validation 선택 모델 공통 예측: 106,644행
- 강우 구성 공통 예측: 186,627행
- 동일 윈도의 각 평가 키마다 Persistence·LightGBM·XGBoost·LSTM 4개가 모두 존재한다.
- 강우 비교의 각 평가 키마다 Persistence와 3개 알고리즘의 B·강우 구성, 총 7개가 모두 존재한다.
- 알고리즘별 평가 키 중복과 실제값 불일치는 0건이다.
- 서로 다른 선택 윈도 비교만 의도적인 키 교집합을 사용한다.
