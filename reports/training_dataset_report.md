# 처리장·유입 관측 계통별 학습 데이터셋 구축 결과

작성일: 2026-11-11

## 예측 계약

- 단위: 날짜 × 물재생센터 × 원본 처리장/유입 관측 계통
- 목표: 다음 날(t+1) 유입 BOD, T-N, T-P
- 입력창: 7일, 14일, 30일
- 분할: 목표일 기준 Train 2016~2022, Validation 2023~2024, Test 2025~2026-09-30
- 처리장 농도 평균과 센터 대표 농도는 생성하지 않았다.
- 모델 학습·스케일링·결측 대치는 수행하지 않았다.

ASOS 후보별로 3,926일이 수집됐고 달력 누락과 일평균기온 결측은 모두 0건이다. 일강수량 공란/결측은 서울 2,345건, 인천 2,446건, 수원 2,381건이다. 공란을 임의로 0으로 바꾸지 않았다.

108 서울을 네 센터 공통 주 관측소로 사용했다. 장기 연속성과 동일 도시권 대표성을 우선한 연구용 선택이며, 센터 현장 기상을 완전히 대표한다고 단정하지 않는다. 112 인천과 119 수원은 이후 민감도 비교 후보로 보존했다.

강수 포함 표본이 급감한 이유는 ASOS sumRn 공란을 0으로 간주하지 않았기 때문이다. 따라서 강수 공란의 공식 의미를 확인하기 전에는 강수 포함 30일 변형을 학습 가능 데이터로 보지 않는다. 3일·7일 누적강수 열은 결합 데이터에 보존했지만 기본 모델 입력에는 추가하지 않았다.

## 누수 검증

- 모든 lag는 목표일보다 최소 1일 과거다.
- 윈도 안에 서로 다른 series_id가 섞이지 않는다.
- 날짜가 끊긴 구간은 연속 윈도로 취급하지 않는다.
- Train/Validation/Test는 목표일로 배정한다.
- 스케일러·결측 대치·이상치 경계는 아직 적합하지 않았다.
- ASOS 일 실측은 t일 종료 후 가용하다는 연구용 가정이다. 실제 운영 예측에서는 공개 지연 또는 과거 예보 스냅샷을 별도 확인해야 한다.

검증 세부 결과는 reports/training_pipeline_validation.json에 기록했다.

## 미완료와 다음 단계

- 서울시 API는 보안상 평문 HTTP 호출을 하지 않아 CSV 대조를 완료하지 못했다.
- 서울시가 HTTPS를 지원하는 안전한 엔드포인트 또는 서버 측 프록시를 제공하면 API 수집과 CSV 대조를 재개한다.
- ASOS 강수 공란의 공식 의미를 확인한 뒤 0mm와 결측을 구분한다.
- 모델 학습 전에는 Train에서만 결측 처리·스케일링 파라미터를 적합하고 Validation/Test에 적용한다.
