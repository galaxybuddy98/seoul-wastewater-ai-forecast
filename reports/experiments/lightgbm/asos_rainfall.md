# ASOS 강수량 검증 및 LightGBM 강수 실험 보고서

## 결론

ASOS 일자료 API의 `sumRn` 공란을 무강수 0mm로 일괄 해석할 공식 규칙은 확인하지 못했다. 따라서 서울 108의 공란 2,345건은 모두 `NaN`으로 유지했고, 0mm로 변환한 공란은 0건이다. 수치로 제공된 0.0mm와 양의 강수량만 관측값으로 보존했다.

강수 결측을 표본 제거 조건에서 제외한 뒤 모델 C·D를 별도 실험으로 학습했다. Validation MAE 기준 실험 최적값은 BOD `D/30일`, T-N `C/30일`, T-P `C/30일`이었다. 기존 최종 모델은 자동 교체하지 않았다.

## 공식 자료 확인

- [기상청 ASOS 자료 설명](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=4)은 일자료에 강수 요소를 제공한다고 설명하지만, `sumRn` 공란을 0mm로 처리한다는 규칙은 제시하지 않는다.
- 같은 공식 페이지의 QC FLAG는 시간·분 자료의 기온·습도·기압·지면온도·풍향·풍속·일조에 대해 0(정상), 1(오류), 9(결측)으로 제공된다. 강수와 일자료는 이 목록에 없으므로 이번 `sumRn` 판정에 사용할 수 없다.
- [기후통계지침](https://data.kma.go.kr/resources/images/publication/%EA%B8%B0%ED%9B%84%ED%86%B5%EA%B3%84%EC%A7%80%EC%B9%A8%282021.5%29.pdf)은 강수일수를 일강수량 0.1mm 이상으로 정의한다. 이는 0.1mm 미만 강수와 무강수의 구분 기준이지 API 공란의 저장 규칙은 아니다.
- [공공데이터포털 ASOS 일자료 서비스](https://www.data.go.kr/data/15059093/openapi.do)는 `sumRn`을 일강수량으로 제공하지만 공란 의미를 별도로 정의하지 않는다.

### 실제 자료 교차검증

서울 108의 3,926일 중 `sumRn` 공란은 2,345일이다. 공란 가운데 2025-05-14는 `sumRnDur=0.5시간`, `n99Rn=1.0mm`였으나 `sumRn`은 공란이었다. 따라서 공란 전체를 단순 무강수로 간주하는 규칙에는 실제 반례가 있다. `n99Rn`은 일강수량과 집계 경계가 달라 대체값으로 사용하지 않았다.

기상자료개방포털 CSV는 현재 세션에서 로그인 다운로드가 필요해 같은 날짜의 파일을 확보하지 못했다. 시간자료 OpenAPI도 현재 인증키에 해당 서비스가 등록되지 않아 HTTPS 호출이 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`로 거부되었다. 이 두 비교는 미확인으로 남기며, 성공한 것처럼 보고하지 않는다.

## 적용한 전처리 규칙

| 원본 상태 | 처리값 | 사유 |
|---|---:|---|
| `sumRn` 수치 0.0 | 0.0mm | API가 명시적으로 제공한 관측값 |
| `sumRn` 양수 | 원 관측값 | 원본 보존 |
| `sumRn` 공란 | NaN | 공식 공란 규칙 미확인 및 지속시간 양수 반례 |
| 오류·실제 결측 | NaN | 임의 대치 금지 |

원본값, 원본 공란 여부, 처리값, 결측표시, 처리 사유, 근거를 `data/processed/asos_daily_rainfall_processed.parquet`에 보존했다. 최근 3일·7일 합계는 기간 안에 NaN이 하나라도 있으면 NaN이다. 일 강수량, 1~3일 전 강수량과 누적값은 예측 대상일보다 최소 1일 앞선 입력행만 모델에 들어간다.

서울 108 처리 결과:

- 원본 일수: 3,926일
- 원본 공란: 2,345건
- 공란에서 0mm 변환: 0건
- 공란에서 NaN 유지: 2,345건

## 결측 허용 전후 표본 수

기존 `quality_weather`는 입력창의 모든 강수값이 있어야 표본을 유지했다. 새 C·D는 수질과 기온만 필수로 두고 강수 NaN을 LightGBM에 전달한다.

| 7일 | Validation | 98 | 5,079 | 5,079 |
| 7일 | Test | 53 | 4,114 | 4,114 |
| 14일 | Train | 72 | 19,105 | 19,105 |
| 14일 | Validation | 7 | 5,072 | 5,072 |
| 14일 | Test | 0 | 4,023 | 4,023 |
| 30일 | Train | 0 | 18,801 | 18,801 |
| 30일 | Validation | 0 | 5,056 | 5,056 |

각 창의 C·D 키는 기존 모델 B와 Train/Validation/Test 모두 완전히 일치한다. 표본 증가가 수질 기준 완화에서 발생하지 않았음을 확인했다.

## 해석상 주의점

- 모델 D에서 BOD가 선택됐지만 C와 Validation MAE 차이는 0.0334에 불과하다. 결측표시의 안정적인 이득으로 단정할 수 없다.
- BOD D/30일의 분할 중요도 중 결측표시 열 비중은 약 0.009%였지만, 트리 분할 중요도는 인과적 기여도가 아니다.
- 강수 관련 열은 수가 많아 선택 모델 분할 중요도의 약 27~29%를 차지했다. 열 개수 편향과 상관된 lag 때문에 기상학적 인과로 해석하면 안 된다.
- 공란 패턴 자체가 관측·기록 방식 또는 미량강수와 연관될 수 있다. 특히 D의 개선을 단순 결측 처리 개선으로 해석하지 않는다.
- 일별 실측 기상은 사후 확정 자료다. 본 평가는 과거시점 강수만 사용하지만, 실제 운영에서 입력 확정 시각을 보장하지 못했으므로 `forecast-validation` 기준상 운영 확정 성능이 아니라 탐색 결과다.

## 남은 문제

1. 기상자료개방포털에서 서울 108 일자료 CSV를 로그인 다운로드하여 API와 동일 날짜를 대조해야 한다.
2. ASOS 시간자료 서비스 활용신청 후 2025-05-14와 무강수 표본의 24시간 강수를 확인해야 한다.
3. 기상청에 `sumRn` 공란, 미량강수, 실제 결측의 저장 규칙을 문의해 전 기간 분류 규칙을 확정해야 한다.
4. 규칙 확정 뒤에만 확인된 무강수 공란을 0mm로 변환하고 C·D를 재평가한다.

## 재현 방법

```powershell
python -m scripts.preprocessing.build_rainfall_experiment_dataset
python -m scripts.training.lightgbm.train_rainfall_lightgbm
python -m pytest
```

기존 기준 모델 파일과 `reports/model_*`은 변경하지 않는다. 새 산출물은 `rainfall_*` 이름과 `results/models/rainfall_experiment_*`에만 저장한다.
